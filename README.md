# Simple Marketplace

Создай много-вендорный маркетплейс похожий на Wildberries, но простой.

Роли пользователей:
- Покупатель: регистрируется, смотрит каталог товаров, фильтрует по категории и цене, добавляет в корзину, оформляет заказ.
- Продавец: регистрируется как продавец, создаёт и редактирует свои товары (название, цена, описание, фото, количество), видит свои заказы.

Функции:
- Общий каталог товаров от всех продавцов.
- Поиск и фильтры.
- Корзина и оформление заказа.
- Личный кабинет продавца со списком его товаров и заказов. 
- Простая комиссия платформы (10%) при заказе.
- Базовая авторизация (email + пароль легкий).
- Используй Supabase для базы данных и авторизации.
