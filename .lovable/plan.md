# План: усиление дизайна + удобная навигация по категориям и в кабинетах

## Цвета и типографика (согласовано)

- **Покупатель** — янтарь-мандарин: `--background:#fffbf5`, `--foreground:#111827`, `--brand:#ea580c`, `--brand-soft:#fde68a`.
- **Продавец** — чистый нуар: `--background:#0a0a0a`, `--surface:#171717`, `--foreground:#ffffff`, `--muted-foreground:#a3a3a3`, `--border:#262626`.
- Шрифты: **Sora** (заголовки) + **Manrope** (текст), подключаются `<link>` в `__root.tsx`.
- Переключение темы по `mode` из Zustand — класс `mode-seller` на `<html>` через `useEffect` в `AppLayout`.

## Навигация — главное этой итерации

### 1. Глобальная шапка (`AppLayout.tsx`)

- Логотип · Категории (выпадающее меню) · Поиск · Избранное · Сообщения · Корзина · Профиль.
- **Сегмент-переключатель Buyer/Seller** справа: два пилла с иконками, активный — в цвет режима. Всегда на виду, не в бургере.
- Хлебные крошки прямо под шапкой на всех вложенных страницах (`Главная / Каталог / Электроника / Смартфоны`).
- Мобильная нижняя навигация: 5 иконок (Главная, Каталог, Избранное, Сообщения, Кабинет) с активной подсветкой в цвет режима.

### 2. Меню категорий (`src/components/CategoryMenu.tsx` — новый)

- **Десктоп**: hover-панель под пунктом «Категории» — двухколоночная (слева список категорий с иконками lucide, справа подкатегории выбранной, снизу промо-плитка «Хиты недели»).
- **Мобиль**: bottom-sheet со списком категорий → тап → вложенный список подкатегорий, кнопка «Назад» вверху sheet.
- Категории и подкатегории — реальные записи из таблицы `categories` (fetch через `queryOptions`, кэш 5 мин).
- Активная категория подсвечивается брендовым цветом, иконка меняет обводку.

### 3. Страница каталога (`src/routes/catalog.tsx` + `catalog.$category.tsx`)

- Слева sticky-sidebar (десктоп) со всеми категориями/подкатегориями, дерево с раскрытием.
- Сверху горизонтальный ряд chip-фильтров: «Все», популярные подкатегории, цена, наличие, рейтинг.
- Хлебные крошки: `Главная / Каталог / Категория / Подкатегория`.
- На мобиле sidebar открывается кнопкой «Категории» → bottom sheet.
- Пустое состояние с CTA «Сбросить фильтры».

### 4. Кабинет покупателя — `BuyerShell` (новая обёртка)

Общий layout для `_authenticated/orders`, `favorites`, `messages`, `profile`, `addresses`:

- **Десктоп**: левый sidebar 260px, sticky, с иконками и счётчиками (непрочитанные сообщения, новые статусы заказов).
  ```text
  👤 Иван Иванов
  ─────────────
  🛍  Мои заказы     (3)
  ❤️  Избранное      (12)
  💬  Сообщения      (2•)
  📍 Адреса
  ⚙️  Профиль
  ─────────────
  → Стать продавцом
  ```
- **Мобиль**: горизонтальные скролл-табы под шапкой + bottom-nav.
- Активный пункт: `bg-brand/10 text-brand`, точка-индикатор слева.

### 5. Кабинет продавца — `SellerShell` (новая обёртка)

Общий layout для всех `_authenticated/seller.*`, форсит `mode-seller`:

- **Десктоп**: левый чёрный sidebar 260px, collapsible до 72px (только иконки), кнопка-стрелка сверху.
  ```text
  🏪 Название магазина      ✎
  ─────────────
  📦 Товары            (48)
  🧾 Заказы            (5•)
  📊 Аналитика
  💳 Баланс            2 340 ₽
  💬 Сообщения         (1•)
  ⚙️ Настройки
  ─────────────
  ← Режим покупателя
  ```
- **Мобиль**: тёмный bottom-sheet nav + верхняя тонкая полоса с названием текущего раздела и кнопкой «Меню».
- Активный пункт: белая заливка на чёрном, hairline-бордер.
- Индикаторы: цветная точка на пункте, если есть новые заказы/сообщения/жалобы.

### 6. Хлебные крошки (`src/components/Breadcrumbs.tsx` — новый)

Универсальный компонент, читает `useMatches()` и строит цепочку. Используется:
- каталог, категория, товар,
- кабинет покупателя (Кабинет / Заказы / Заказ #1234),
- кабинет продавца (Продавец / Товары / Редактировать).

### 7. Кнопка «Назад»

- На карточке товара, странице заказа, чате, редактировании товара — кнопка `← Назад` в цвет режима с `router.history.back()` + fallback `Link to=".."`.

### 8. Быстрые ссылки на главной

- Плитки категорий (8 штук) с иконками lucide кликают в `/catalog/$category`.
- «Продолжить покупки» — блок с последними просмотренными (из `localStorage`).
- CTA «Стать продавцом» — переход в `/auth?role=seller` в тёмном стиле.

## Общий редизайн (без изменения бизнес-логики)

- Все цвета через CSS-переменные и семантические классы Tailwind. Никаких хардкодов.
- Иконки — lucide, `strokeWidth={1.75}`, 20px в кнопках / 22px в навигации.
- Кнопки — только shadcn `Button` (primary/secondary/ghost/outline).
- Плавные `transition-colors duration-200`, hover-подъём карточек `duration-300`.
- Focus-ring в цвет режима для доступности.

## Технические детали

- Категории читаем через `queryOptions({ queryKey:["categories"], queryFn: … })` c `staleTime: 5*60_000`; используется и в `CategoryMenu`, и в `CategorySidebar`.
- Счётчики в sidebar (новые заказы, непрочитанные сообщения) — `useSuspenseQuery` с polling 30s либо Realtime-подписка там, где уже настроена.
- `SellerShell` форсит `mode==='seller'` через `useEffect(() => setMode('seller'), [])`, `BuyerShell` — `buyer`. Прямая ссылка в кабинет автоматически включает нужную тему.
- Хлебные крошки резолвят человеческие названия по route `staticData: { label: "…" }`.
- Bottom-nav скрывается на страницах чата (мешает клавиатуре) через `hideBottomNav` в staticData.
